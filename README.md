# Perfect Stack

## Short description

Build the tallest tower with precise block placement.

## Description

Perfect Stack is a lightweight, multilingual tower-stacking game for the browser. Players place moving blocks on top of one another, earn bonuses for precise alignment, build combos, and compete against their locally saved records.

## Purpose

The extension offers a quick precision and timing challenge that is easy to play from the browser toolbar and encourages users to improve their consistency and high score.
