# Privacy Policy for Perfect Stack

Perfect Stack does not collect personal information, browsing history, website content, location data, or advertising identifiers. All game logic runs within the extension popup, and the extension does not use advertising, analytics, or user tracking. Game data is not sent to a server, sold, or shared with third parties.

## Data Stored

The extension stores language, sound, and reduced-motion preferences, together with the best score, tallest tower, and best perfect-placement streak. This data is stored locally and is used only to personalize the game and display the user's records.

## Why the `storage` Permission Is Required

The `storage` permission is required only to preserve game settings and records between sessions. It does not allow the extension to read personal files, browsing history, or website content, and it is not used to transmit data over the internet.

## External Link

The donation link opens an external website only when selected by the user. The privacy policy of that website applies after the user leaves the extension.
